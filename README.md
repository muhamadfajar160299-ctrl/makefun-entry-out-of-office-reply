An entry for the [Funniest One-Line Out-of-Office Reply](https://make.fun/bounty/u-hamsyh-funniest-one-line-out-of-office-reply-5490c1c8) competition on make.fun.

## The entry

> I'm out of office — my inbox is being watered by a neighbour, and only the spam is thriving.

## How it works

`main.py` (Python 3, standard library only) copies the entry text shipped
beside it (`entry.txt`) byte-for-byte to `$MAKEFUN_OUTPUT_DIR/entry.txt`
with mode `0644`. It refuses to write an empty or whitespace-only entry.
